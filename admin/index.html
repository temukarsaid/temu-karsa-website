      Hubungkan Google Analytics untuk menampilkan pengunjung di sini

      1. Di Google Cloud Console, buat service account lalu unduh kunci JSON-nya, dan aktifkan Google Analytics Data API.
      2. Di Google Analytics → Admin → Property access management, tambahkan email service account itu sebagai Viewer.
      3. Di Cloudflare Pages → Settings → Environment variables, isi GA4_PROPERTY_ID (angka property id, bukan G-XXXX), GA4_CLIENT_EMAIL, dan GA4_PRIVATE_KEY dari file JSON tadi.
